# Caro-Period-Tracker-Android
A simple native Android app for tracking the menstrual cycle.


## Project Overview
**Current status:** Active development &rarr; MVP design

Over the years, I have used many popular menstruation tracking apps, consistently encountering recurring UX friction points and/or missing features. These experiences, together with a rise in data privacy concerns, led me to build Caro: a native Android application designed around privacy, usability, and the real-world needs of at least one user.

This project follows a structured end-to-end software engineering lifecycle, moving from initial market research and UI prototyping to architecture design, requirements documentation, code implementation, and thorough testing.
